# Иллюстрации Fluent Emoji (High Contrast)

Источник: https://github.com/microsoft/fluentui-emoji — © Microsoft Corporation, лицензия MIT (см. LICENSE.txt).
Используются как исходники контурных картинок больших карт: `tools/render_svg.gd` рендерит SVG в PNG,
`tools/gen_picture_maps.py` собирает из них маски карт `maps/pic/*.png`.
